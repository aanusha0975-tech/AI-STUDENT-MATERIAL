# 📚 AI Student Material

## 🚀 About the Project

AI Student Material is an AI-powered learning assistant designed to help
students understand and prepare study material easily.

Students can enter a topic or upload a PDF study material and generate
learning content using AI.

## 🎯 Problem

Students often spend a lot of time searching for notes, important questions,
MCQs and exam preparation material from different sources.

## 💡 Solution

AI Student Material provides these learning resources in one application.

The student can enter a topic and select the type of material they need.

## ✨ Features

- 📚 AI-generated study notes
- ❓ Important questions
- 🎯 Multiple-choice questions (MCQs)
- 💡 Questions and answers
- 📖 Exam preparation material
- 📄 PDF study material upload
- 🤖 AI-powered content generation
- 🎓 Simple and student-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenAI API
- PyPDF
- python-dotenv
- GitHub

## ⚙️ How It Works

1. Student opens the application.
2. Student enters a study topic.
3. Student selects the required learning material.
4. Student can optionally upload a PDF.
5. AI processes the topic or study material.
6. The application generates useful learning content.
